# iap-kit

Open-source In-App Purchase (IAP) backend kit for iOS and Android.
Built with NestJS, Angular, and Ionic.

## Stack
- **api** — NestJS (receipt validation, webhooks, sync)
- **admin** — Angular (product management, purchase tracking) - Mika Engine
- **app** — Ionic Angular (mobile demo)
